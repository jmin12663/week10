# 같이 타요 — 학교 택시 파티 모집 서비스

같은 시간, 같은 방향으로 가는 학교 사람끼리 택시를 나눠 타도록 모집글을 올리고, 최대 4명이 실시간 채팅으로 만날 위치를 정하는 웹서비스입니다.

- 배포 주소: `http://<EC2 퍼블릭 IP 또는 DNS>` ← 배포 후 작성
- 저장소: https://github.com/jmin12663/week10

## 1. 서비스 소개

**대상 사용자**: 수업이 끝나는 시간, 금요일 하교, 시험 마지막 날처럼 같은 시간대에 역·터미널로 가는 학생

**만든 이유**: 에브리타임 게시판으로 택시 인원을 구하면 댓글·쪽지로 일일이 연락해야 하고, 인원이 찼는지 실시간으로 알 수 없습니다.

**핵심 기능**

| 기능 | 설명 |
|---|---|
| 회원가입·로그인 | 아이디·비밀번호·학번·학과·이름으로 가입. 다른 사용자에게는 `학과 + 가린 이름(신*민)`만 보이고 학번은 공개하지 않음 |
| 파티 모집글 | 만나는 장소·목적지·출발 시간으로 생성. 작성자가 방장. 목적지·날짜로 검색 |
| 파티 입장 | 최대 4명. 여러 명이 동시에 입장해도 4명을 넘지 않음. 목록의 인원(2/4 → 3/4)이 새로고침 없이 바뀜 |
| 실시간 채팅 | 참여자끼리 WebSocket 채팅. 입장·퇴장·수정 내용이 시스템 메시지로 자동 안내 |
| 방장 관리 | 모집글 수정·삭제(삭제 시 채팅방도 함께 삭제), 불참자 강퇴(강퇴된 사람은 재입장 불가) |

**규칙**
- 출발 시간은 지금 이후 7일 이내만 가능, 출발 시간이 지나면 자동 마감
- 방장은 나갈 수 없고 모집글 삭제만 가능 (작성자 = 방장 유지)

## 2. AWS 구성도

```
                 ┌──────────────────────── EC2 (보안 그룹: 80 허용) ────────────────────────┐
브라우저 ──HTTP──▶│  nginx 컨테이너 :80                                                        │
  (HTML·JS)      │   ├─ /            → 정적 파일 (html, js, css)                              │
          ◀─WS──▶│   └─ /api/, /api/ws/ → api 컨테이너 :5000 (Flask + flask-sock)             │
                 │                          └─ SQLite 파일 → data 볼륨 (/data/taxi.db)        │
                 └──────────────────────────────────────────────────────────────────────────┘
```

**요청 경로**
- 화면: 브라우저 → EC2:80 → nginx → 정적 파일
- REST API: 브라우저 → nginx `/api/...` → Flask
- 실시간: 브라우저 ↔ nginx `/api/ws/...` (WebSocket 업그레이드) ↔ Flask

**통신 방식을 나눈 이유**
- 상태를 바꾸는 작업(가입, 생성, 입장, 나가기, 강퇴, 수정, 삭제)은 **REST**: 요청마다 성공/실패가 HTTP 상태 코드(409 정원 초과, 403 권한 없음 등)로 바로 돌아와 오류 처리와 시험 기록이 명확함
- 채팅과 변경 알림은 **WebSocket**: 서버가 먼저 보낼 수 있어 메시지·인원 변화가 즉시 반영되고, 폴링처럼 빈 요청이 반복되지 않음

**사용한 AWS 서비스와 선택 이유**

| 서비스 | 역할 | 선택 이유 |
|---|---|---|
| EC2 | Docker Compose로 nginx·api 컨테이너 실행 | 로컬에서 확인한 Compose 구성을 그대로 실행할 수 있음 |

**ELB·Auto Scaling 검토**

- **몰리는 상황**: 수업 종료·하교 시간에 목록 조회와 입장이 집중됨
- **현재 미적용**, 이유:
  1. 실시간 연결(WebSocket)을 서버 메모리에서 관리하고, 데이터는 서버 안의 SQLite 파일에 저장하므로 **서버를 2대 이상으로 늘리면 서버 간에 채팅·데이터가 공유되지 않음**
  2. 학교 단위 사용자 수에서는 EC2 1대로 처리 가능하고, ALB·추가 인스턴스는 사용자가 없는 시간에도 비용이 발생함
- **확장한다면 필요한 변경**
  - SQLite → RDS(MySQL 등)로 데이터 공유
  - 서버 간 메시지 전달용 Redis Pub/Sub(ElastiCache) 추가
  - ALB는 WebSocket을 지원하지만, 이미 연결된 WebSocket은 새 서버가 추가돼도 기존 서버에 붙어 있으므로 새 연결부터 분산됨
  - Auto Scaling 그룹에 최대 서버 수를 두고 예산 알림으로 비용 상한 관리

## 3. 실행·배포

### 준비 사항
- Docker, Docker Compose
- (선택) 포트를 바꾸려면 프로젝트 폴더에 `.env` 작성: `WEB_PORT=8080` (기본값 80)
- compose의 `ADMIN_PASSWORD`는 이전 버전에서 쓰던 값으로 현재는 사용하지 않음

### 로컬 실행
```bash
docker compose config            # 설정 검사
docker compose up -d --build     # 빌드 후 실행
curl http://localhost/api/health # {"status":"ok", ...} 확인
```
브라우저에서 `http://localhost` 접속 → 회원가입 → 로그인

### EC2 배포
```bash
# EC2 접속 후 (Amazon Linux 2023 기준 예시, 실제 사용한 명령으로 수정)
sudo dnf install -y docker git
sudo systemctl enable --now docker
# docker compose 플러그인 설치 (수업 자료 방법대로)
git clone https://github.com/jmin12663/week10.git
cd week10
sudo docker compose up -d --build
```
- 보안 그룹 인바운드: TCP 80 (또는 `WEB_PORT`) 허용
- 접속 주소: `http://<EC2 퍼블릭 IP>`

| 항목 | 값 |
|---|---|
| 외부 포트 | 80 (`WEB_PORT`) |
| nginx 컨테이너 | 80 |
| api 컨테이너 | 5000 (외부 비공개, nginx만 접근) |
| 데이터 | Docker 볼륨 `notice_data` → `/data/taxi.db`, 세션 키 `/data/secret_key` |

## 4. 검증 (배포 주소에서 시험)

시험 환경: `<브라우저/OS, 배포 주소>` ← 작성

| 기능 | 구분 | 입력 | 기대 결과 | 실제 결과 |
|---|---|---|---|---|
| 회원가입 | 정상 | 새 아이디·학번으로 가입 | 가입 완료 후 로그인 화면 | |
| 회원가입 | 실패 | 이미 있는 아이디로 가입 | "이미 사용 중인 아이디입니다." (409) | |
| 로그인 | 실패 | 틀린 비밀번호 | "아이디 또는 비밀번호가 올바르지 않습니다." (401) | |
| 파티 생성 | 정상 | 정문 → 양주역, 30분 뒤 | 채팅방 이동, 다른 사용자 목록에 즉시 표시 | |
| 파티 생성 | 실패 | 지난 출발 시간 | "출발 시간은 현재 이후여야 합니다." (400) | |
| 파티 입장 | 정상 | 브라우저 B에서 입장 | A 화면 인원 1/4 → 2/4 실시간 반영 | |
| 파티 입장 | 경계 | 4명 찬 파티에 5번째 입장 | "정원(4명)이 가득 찼습니다." (409) | |
| 실시간 채팅 | 정상 | A에서 메시지 전송 | 같은 방 B 화면에 즉시 표시 | |
| 실시간 채팅 | 실패 | 공백만 전송 | 전송되지 않음 / 서버 거부 | |
| 모집글 수정 | 정상 | 방장이 만나는 장소 변경 | B 화면 정보 갱신 + 변경 안내 메시지 | |
| 모집글 수정 | 실패 | 방장 아닌 사람이 수정 요청 | "방장만 수정할 수 있습니다." (403) | |
| 강퇴 | 정상 | 방장이 B 강퇴 | B 화면이 목록으로 이동 | |
| 강퇴 | 실패 | 강퇴된 B가 재입장 | "강퇴된 파티에는 다시 입장할 수 없습니다." (403) | |
| 모집글 삭제 | 정상 | 방장이 삭제 | 참여자 화면이 목록으로 이동, 목록에서 사라짐 | |

**동시 입장 시험** (`tests/test_api.py`): 방장 1명이 있는 파티에 7명이 동시에 입장 요청 → 3명 성공(201), 4명 실패(409), 최종 인원 4명

```bash
python3 tests/test_api.py http://<배포 주소>    # REST API 전체 시험
pip install simple-websocket
python3 tests/test_ws.py http://<배포 주소>     # WebSocket 실시간 시험
```
> 시험 스크립트는 시험용 계정과 파티를 만들기 때문에, 시연 전 데이터를 비우려면 `docker compose down -v` 후 다시 실행합니다.
